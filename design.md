# Design System: Lands in Brazil

## Core Principles
- **Modern & Dynamic:** Clean layouts, generous whitespace, high-end feel.
- **Dynamic Interaction:** Smooth transitions, responsive carousel, interactive elements.
- **Authenticity:** Professional imagery paired with clear, concise communication.

## Style Guide
- **Typography:**
  - Headings: "Familjen Grotesk" (Strong, geometric sans-serif)
  - Body: "Newsreader" (Sophisticated serif for readability)
- **Palette:**
  - Background: #f1ead8 (Sophisticated Cream/Beige)
  - Text/Ink: #1d2a22 (Dark Forest)
  - Accent: #b9831f (Gold)
- **Components:**
  - Modern Card Layouts (Grid).
  - Immersive carousel with video-first experience.

## Technical Requirements
- Native CSS Grid/Flexbox for responsiveness.
- Performance: Optimized images (WebP/JPEG).
- Form: Modern UI, clear feedback, secure submission.
